# 🖥️ Desktop Automation & Corpus Tool (桌面智能语料与高效贴图录制工具)

一款基于 Python (Tkinter) 开发的轻量级桌面效率工具。专为日常办公、文档编写、自动化测试及语料搜集设计，集成了 **OCR 范围采集**、**SOP 自动化步骤录制** 与 **多功能置顶贴图工具箱**。

---

## ✨ 核心功能特性

### 1. 🔍 智能 OCR 语料采集
* **可视化框选**：支持通过快捷键或界面自由指定屏幕采集区域（带红色提示边框）。
* **自动去重过滤**：后台多线程高频截屏并利用 RapidOCR 提取有效文本，自动按字数降序排序并导出为 Excel 表格。

### 2. 📝 SOP 操作步骤录制 (自动生成 Word)
* **点击追踪**：一键开启步骤录制，自动捕获全局鼠标点击事件（智能过滤自身软件点击）。
* **图文并茂**：每次点击后自动截图并记录坐标与时间，停止录制后一键生成排版规范的 Word 操作指南（`.docx`）。

### 3. 📌 高效贴图工具箱 (Pin)
* **局部截图贴图**：通过快捷键一键截取屏幕任意区域并将其作为无边框/带边框的置顶悬浮窗固定在桌面上。
* **便捷交互**：
  * **双击**：瞬间隐藏/缩起贴图。
  * **右键菜单**：支持一键复制图片到系统剪贴板（可直接 `Ctrl+V` 贴入聊天或文档）、切换边框显示、隐藏或销毁。
* **全局唤出**：支持通过全局快捷键瞬间将隐藏的贴图重新调回桌面。

---

## ⌨️ 默认全局快捷键

| 功能动作 | 默认快捷键 | 说明 |
| :--- | :--- | :--- |
| **截图贴图 (Pin)** | `F3` | 框选屏幕并生成悬浮置顶贴图 |
| **显示/调出贴图** | `F4` | 瞬间恢复显示所有被隐藏的贴图 |
| **选择采集范围** | `Alt + W` | 框选 OCR 采集或步骤录制的监听区域 |
| **开始/停止录制步骤** | `F1` | 切换开始录制或停止并导出 Word |
| **销毁所有贴图** | `ESC` | 清理并关闭所有桌面贴图窗口 |

> *💡 提示：所有快捷键均可在软件界面的【快捷键自定义设置】中根据个人习惯随时更改！*
